# EggDex

Eine moderne, vollständig statische Companion-Web-App. Erstellt von **JM Code Studio**.

## Funktionen

- EggDex mit Suche, Filtern und Sortierung
- Persönliche Sammlung, Mengen und Favoriten
- Automatische Speicherung im Browser (localStorage)
- Einkommensrechner und Tiervergleich
- Biome, Event-Aufgaben und lokaler Adminbereich
- JSON-Backup mit Import und Export
- Dark/Light Mode und responsives Design
- Automatische Veröffentlichung über GitHub Pages

## Lokal starten

Öffne einfach `index.html` im Browser. Es ist keine Installation nötig.

## Auf GitHub Pages veröffentlichen

1. Erstelle ein neues öffentliches GitHub-Repository, zum Beispiel `egg-dex`.
2. Lade den gesamten Inhalt dieses Ordners hoch.
3. Öffne im Repository **Settings > Pages**.
4. Wähle unter **Source** den Eintrag **GitHub Actions**.
5. Der enthaltene Workflow veröffentlicht die App automatisch.

Danach ist die App typischerweise unter `https://DEIN-NAME.github.io/egg-dex/` erreichbar.

## Wichtiger Hinweis

Daten werden lokal im jeweiligen Browser gespeichert. Nutze regelmäßig die Backup-Funktion. Dieses Projekt ist ein inoffizielles Fanprojekt und steht nicht in Verbindung mit Roblox oder den Erstellern des Spiels.
